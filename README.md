# TinyTools

Small tools for everyday jobs, with no account needed.

## What it does

- **Guest sign-in:** press "Continue as guest" and start using the tools straight away.
- **Currency converter:** convert an amount between US dollars, euros, pounds and Indian rupees. An empty, non-numeric or negative amount shows a clear message.
- **Todo list:** add a todo, tick it off and delete it. Your list is still there after a page reload.

## Run the tests

```
npm test
```
